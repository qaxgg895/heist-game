The Marlow Job is a top-down gallery heist game where you play Wren, a thief slipping through the Marlow Gallery after hours. Dodge the guards' vision cones and the sweeping cameras, steal the Marlow Star diamond from the vault, and escape through the service exit before the alarm catches you.

## Run it

```sh
node serve.ts
```
